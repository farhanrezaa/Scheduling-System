# Logo Setup Guide

The app now supports displaying the WIDYS company logo!

## How to Add Your Logo

1. **Place your logo image file** in the `scheduling_system` directory with one of these names:
   - `logo.png` (recommended)
   - `logo.jpg`
   - `widys_logo.png`
   - `widys_logo.jpg`

2. **Or create an `assets` folder** and place it there:
   - `assets/logo.png`
   - `assets/widys_logo.png`

## Logo Display

The logo will appear in two places:
- **Main page header** (top left, next to the title)
- **Sidebar** (at the very top)

## Fallback

If no logo image file is found, the app will automatically display a text-based logo with:
- **WIDYS** (in red)
- **BIMBINGAN BELAJAR** (in red, bold)
- **#EdukasiDenganHati** (in red, italic)

## Recommended Logo Specifications

- **Format:** PNG (with transparency) or JPG
- **Size:** 200-400px width (height will scale proportionally)
- **Aspect Ratio:** Any (will be scaled to fit)

The logo will automatically resize to fit the container width.
